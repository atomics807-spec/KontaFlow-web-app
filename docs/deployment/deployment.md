# Deployment

KontaFlow runs unchanged on Vercel (Node runtime) and Cloudflare (Workers via
OpenNext). Configuration comes exclusively from environment variables; nothing
in application code depends on a platform SDK.

## Pre-flight

```bash
npm ci
npm run typecheck
npm test
npm run test:db      # optional but recommended: rebuilds a throwaway DB
npm run build
```

## Environment

Set every variable from `.env.example`. Minimum for a working app:

| Variable | Notes |
| --- | --- |
| `NEXT_PUBLIC_APP_URL` | Canonical HTTPS origin, no trailing slash |
| `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Public client config |
| `SUPABASE_SERVICE_ROLE_KEY` | Server only; required by USSD, WhatsApp, cron |
| `RESEND_API_KEY`, `EMAIL_FROM`, `EMAIL_REPLY_TO` | Invitations and daily digest |
| `CONTACT_INBOX_EMAIL` | Destination for public contact form notifications (defaults to `info@kontaflow.com`) |
| `OPENAI_API_KEY`, `OPENAI_MODEL` | Assistant; omit to disable cleanly |
| `WHATSAPP_*` | Phone number id, access token, verify token, app secret |
| `USSD_SERVICE_CODE`, `USSD_CALLBACK_TOKEN` | Africa's Talking callback |
| `SMS_PROVIDER=africastalking` + `AFRICASTALKING_*` | Phone OTP delivery; `none` blocks onboarding, `console` is local-only |
| `OTP_HMAC_SECRET` | Dedicated 32-byte secret for OTP hashing; do not reuse the service-role key |
| `CRON_SECRET` | Bearer token for `/api/cron/daily-digest` |

Never commit `.env.local`. Vercel stores encrypted env vars per environment;
Cloudflare uses `wrangler secret put` or the dashboard.

## Vercel

1. Import the repository; the preset is auto-detected (Next.js).
2. Add environment variables for Production and Preview.
3. Deploy. Route handlers run on the Node runtime (needed for `node:crypto`
   HMAC verification and the Supabase SDK).
4. Schedule the digest with `vercel.json`:

```json
{
  "crons": [{ "path": "/api/cron/daily-digest", "schedule": "0 18 * * *" }]
}
```

18:00 UTC is 19:00 in `Africa/Douala`. Vercel sends
`Authorization: Bearer $CRON_SECRET` automatically when the env var is set.

5. Point Cloudflare DNS at Vercel and keep the proxy (orange cloud) on for WAF,
   TLS and caching of static assets.

## Cloudflare

OpenNext compiles the same Next.js app to a Worker with static assets in R2/KV
bindings generated by the adapter.

```bash
npm run preview:cloudflare
npm run deploy:cloudflare
```

1. `wrangler.jsonc` must configure `compatibility_flags = ["nodejs_compat"]`
   (already required by the adapter) and the R2/KV bindings OpenNext asks for.
2. Add secrets: `npx wrangler secret put SUPABASE_SERVICE_ROLE_KEY`, plus the
   other server-only values.
3. Add the custom domain in Cloudflare and enable WAF managed rules.
4. Schedule the digest with a Cron Trigger and a Worker fetch to the route, or
   use Cloudflare Snippets/Workers Cron to call
   `https://app.example.com/api/cron/daily-digest` with the bearer token.
5. Edge caching: keep HTML on `no-store` (dynamic, per-tenant); static assets
   (`/_next/static/*`, `/icons/*`) can be cached aggressively.

### Portability notes

* No Vercel KV/Blob/Postgres or `@vercel/*` imports.
* `next/image` optimization falls back to the adapter default on Cloudflare;
  use explicit dimensions and remote patterns for Supabase storage URLs.
* File uploads go to Supabase Storage, not the platform filesystem.
* Long-running jobs are avoided; the digest processes at most 200 workspaces per
  invocation and can be sharded with an env-driven offset if needed.

## Database rollout

1. Apply migrations with `supabase db push` (or `npm run db:push` against
   `SUPABASE_DB_URL`) before deploying code that depends on them.
2. `0010` grants its wrappers to `service_role` only; verify with
   `select has_function_privilege('authenticated', 'public.record_channel_transaction(uuid,uuid,public.entry_channel,jsonb)', 'execute')` → `false`.
3. Keep a Postgres backup/PITR window before applying destructive changes.

## Post-deploy smoke test

1. Sign up, confirm email, receive the SMS code, verify the phone, complete
   onboarding → dashboard loads. Without a working SMS provider the phone gate
   blocks workspace creation by design.
2. Record income and expense; dashboard and reports reflect them.
3. Invite a teammate, accept the link in a private window, verify isolation in
   the new session (no access to your business unless invited).
4. `GET /api/whatsapp?hub.mode=subscribe&hub.verify_token=...&hub.challenge=ok`
   returns `ok`; a signed POST reaches the assistant.
5. `curl -H "Authorization: Bearer $CRON_SECRET" https://.../api/cron/daily-digest`
   returns `{ "processed": n, ... }`.
6. Response headers include CSP and HSTS.
